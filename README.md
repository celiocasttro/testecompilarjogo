# Desvie dos Blocos 🎮

Jogo Android simples para teste. Arraste o jogador para desviar dos blocos que caem e tente fazer a maior pontuação.

## APK
O GitHub Actions compila o APK automaticamente ao enviar alterações. Acesse a aba **Actions**, abra a execução mais recente e baixe o artefato `desvie-dos-blocos-apk`.
